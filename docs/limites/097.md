# Limite #97

97. **Machine XYZAB (tête A puis B, plateau en Y) : profil, export G-code, filtre médian des axes ; éventail sous les
    plafonds en prototype (2026-11-27).**

    - **Origine** : dessin de l'utilisateur (couches des parois qui se referment en éventail sous le plafond de la
      cabine du Benchy, toit lissé à plat, buse à l'horizontale sur le rebord de la cheminée). Sur l'Aetheris-4, C est
      imposé par la position (limite #59) : la tête ne penche que vers l'extérieur du plateau, un plafond tenu des deux
      côtés ne peut pas être refermé en éventail. Décision de l'utilisateur : « il est temps de refaire la
      cinématique » ; plan : `docs/CINEMATIQUE_XYZAB.md`.
    - **Fait** :
      - profil `res/machines/apex-xyzab.json` : `kinematics = "head-ab"`, axes de la tête A (autour de X) puis B (autour
        de Y), ± 180°, plateau carré 220 mm (`platform_size`), `pivot_to_tip` = 40 mm PROVISOIRE (rappel permanent),
        aucun axe imposé par la position ; nouveaux champs facultatifs de `MachineProfile` (`kinematics`,
        `platform_size`, `pivot_to_tip`), `radial_direction` devenu facultatif ;
      - `file_io/gcode_xyzab.py` : G-code `G01 X Y Z A B`, position du PIVOT = pointe + L R_A R_B (0, 0, 1), mouvements
        découpés pour que la pointe reste à `max_tip_deviation` de sa droite, description `apex-kinematics/1` de la
        machine ; `export_gcode` y bascule selon `MachineProfile.kinematics` ;
      - étape 8, `_median_filter_free_axes` : avec deux axes libres, la médiane de chaque axe pris séparément mélange
        les deux solutions de la rotule (l_shape : 164 orientations « inatteignables » créées par le filtre, aucune
        sans lui) ; un point que le filtre écarte de plus d'1° de plus de sa direction reprend ses angles résolus. Une
        machine à un seul axe libre (Aetheris-4) n'est pas touchée ;
      - `PlanarParams.lean_deg` (0 = inactif) : près d'un surplomb à incliner, direction de croissance penchée vers le
        vide depuis l'appui le plus proche.
    - **Mesures** (Benchy, finesse 1,5, temps 300 000, natif) :
      - machine XYZAB, réglages par défaut : sans appui 67,7 mm (Aetheris-4 : 65,9) ; l_shape : 0 orientation
        inatteignable (Aetheris-4 : 2 001) ;
      - éventail (`bridge_span = 0`, `lean_deg = 45`) : la cabine se referme bien en arche (coupes), mais sans appui
        67,7 → 408,5 mm : `bridge_span = 0` incline TOUS les plafonds et un éventail naïf pose de la matière dans le
        vide. Reste inactif.
    - **Limites** :
      - export XYZAB en Python seul (Benchy : environ 9 min d'écriture, contre quelques secondes en natif pour
        l'Aetheris-4) ;
      - aucun modèle 3D de la nouvelle tête : collisions de la tête non vérifiées (étape 9 dégradée), dégagements non
        contrôlés ;
      - pas de bloc d'en-tête chiffré dans le G-code XYZAB ;
      - l'Aetheris-4 reste la machine par défaut.
